# Roadmap

Implemented in alpha.2: adapted SPhone phone/artwork/apps, rechargeable removable batteries and whole-device charging, standard FE input, powered configurable cell/WiFi/wired LAN/WAN, encrypted rack packages/cartridges, optional voice API calls and OC2 device callbacks.

Next validation: two-player Simple Voice Chat under disconnect/power/coverage loss; full Flux/Create Power Grid/AE2/OC2R modpack; survival balancing, automation and multiplayer soak testing.

Future features: distinct WAN/LAN routing semantics, server-stack topology and address management, configurable link bandwidth/latency, network administration, richer package/application distribution, dedicated camera capture and gallery sharing, deeper AE2/OC2 interfaces. Existing features do not imply these are already complete.

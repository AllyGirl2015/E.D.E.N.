# Feature status and next milestones

| Feature | Alpha status | Remaining work |
|---|---|---|
| Phone, tablet, laptop | Implemented as handheld devices | Dedicated models/animations, battery and durability |
| Desktop | Placeable terminal with shared UI | Facing, richer furniture models and peripheral support |
| SIM/number identity | Implemented | Provider plans, operator recovery and explicit transfer controls |
| Native world persistence | Implemented | Migration tooling, configurable retention, large-server profiling |
| SMS/contacts | Implemented | Conversations, unread counters, notifications and MMS |
| Notes/calculator/weather/themes | Implemented | Multiline editor, forecast, accessibility/localization polish |
| Shared app/service API | Implemented, experimental | Stable API contracts and addon sample project |
| In-game developer toolkit | Text apps and bulletin services | Visual form editor, navigation/actions, permissions and richer service templates |
| Voice calls | Not implemented | Call lifecycle, Simple Voice Chat adapter, privacy/cleanup tests |
| Towers/carriers/SIM tiers | Not implemented | Coverage, powered range, admin/creative SIM rules |
| Power integrations | Not implemented | NeoForge energy and Create-specific adapters, verified against their versions |
| Wi-Fi, routers, Ethernet and internet | Not implemented | Network graph, subscriptions, device transport adapters |
| Banking/currency | Not implemented | Server-side ledger, transaction atomicity and permissions |
| Transport services | Not implemented | Provider registry, route/dispatch UI, integrations |
| Camera/gallery/app store | Not implemented | Storage/access controls, installation/catalog controls |
| SPhone/Device Mod binary compatibility | Not supported | Explicit adapter/migration projects if later requested |

Next: dedicated-server/client smoke testing and multiplayer playtesting of the alpha; then voice calling and powered network coverage. Banking/transport follow when their world systems and rules are defined. The full E.D.E.N. civilization platform is not complete in this branch.
